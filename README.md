# 🎮 Stone–Paper–Scissors Game (Python Project)

## 📌 Overview

This is a simple command-line based **Stone–Paper–Scissors** game built using Python. The player competes against the computer, which randomly selects its move. The game continues until the user decides to exit.

---

## 🚀 Features

* 🎯 User vs Computer gameplay
* 🤖 Random computer choices
* 🧠 Win / Lose / Draw logic
* 🔁 Play multiple rounds in a loop
* 🚪 Exit option anytime

---

## 🛠️ Technologies Used

* Python (Basic concepts)

  * Functions
  * Loops
  * Conditional statements
  * Random module

## ▶️ How to Run

1. Make sure Python is installed on your system.
2. Download or clone this project.
3. Open a terminal or command prompt.
4. Navigate to the project folder.
5. Run the program:

```id="k29d8s"
python game.py
```

---

## 🧠 How It Works

* The user inputs **stone**, **paper**, or **scissors**.
* The computer randomly selects one option.
* The program compares both choices and decides the result:

  * Stone beats Scissors
  * Scissors beats Paper
  * Paper beats Stone
* The result (Win/Lose/Draw) is displayed.
